# Облік замовлень

Простий вебзастосунок для обліку замовлень за договорами.
Стек: Node.js 20+, Express 5, EJS, PostgreSQL.

## Можливості

- **Замовлення (договір)**: зовнішній номер договору, контрагент, дата договору,
  орієнтовна дата поставки, файл договору, примітки.
- **Найменування (товар)** у договорі: замовлена кількість та одиниця виміру. Для кожного
  найменування автоматично рахуються:
  - **отримано** — сума всіх поставок;
  - **не зможуть** — кількість, від якої відмовився постачальник (з причиною);
  - **очікуємо** = замовлено − отримано − не зможуть.

  Наприклад: замовили 100, отримали 20, 20 не зможуть → очікуємо 60.
- **Поставки**: дата, номер накладної, скан накладної, кількість по кожному найменуванню.
  Не можна прийняти більше, ніж очікується.
- **Пошук**: за номером договору, контрагентом, найменуванням, періодом дати договору
  та станом (очікується / частково поставлено / прострочено / виконано). Пошук не
  залежить від регістру, зокрема для кирилиці.

## Сторінки

| Сторінка | Адреса |
|---|---|
| Перегляд і пошук | `/contracts` |
| Створення замовлення | `/contracts/new` |
| Картка договору (стан, поставки) | `/contracts/:id` |
| Додати поставку | `/contracts/:id/deliveries/new` |
| Недопоставка / зміна орієнтовної дати | `/contracts/:id/update` |
| Редагування договору | `/contracts/:id/edit` |

## Запуск

### Docker Compose (застосунок + PostgreSQL)

```bash
docker compose up --build
```

Відкрийте http://localhost:3000.

### Локально

Потрібен PostgreSQL зі створеною базою (наприклад, `createdb orders`).

```bash
npm install
DATABASE_URL=postgres://postgres:postgres@localhost:5432/orders npm start
```

Таблиці створюються автоматично при старті (міграції з `migrations/`, кожна
застосовується один раз). Завантажені файли зберігаються в `data/uploads`.
Налаштування — через змінні середовища, див. `.env.example`.

## Тести

Інтеграційні тести працюють з окремою базою, яку **повністю очищують** перед запуском:

```bash
createdb orders_test
TEST_DATABASE_URL=postgres://postgres:postgres@localhost:5432/orders_test npm test
```

## Структура

```
migrations/      SQL-міграції
src/app.js       налаштування Express
src/routes/      договори, поставки, файли
src/lib/         запити до БД, валідація, форматування, зберігання файлів
views/           шаблони EJS
public/          CSS/JS
```

## Зміни схеми БД

Додайте новий файл `migrations/NNN_опис.sql` — він застосується при наступному старті
(або `npm run migrate`).
